# Architecture — Alexandrite

Проектная работа по архитектурному развитию IT-ландшафта компании «Александрит».

Компания производит ювелирные изделия, принимает B2C- и B2B-заказы и использует три основных приложения:

- **Online Shop** — клиентский интернет-магазин;
- **CRM** — работа с заказами и клиентами;
- **MES** — расчёт стоимости и управление производством.

После роста бизнеса и открытия B2B API система столкнулась с потерей/зависанием заказов, длительным pricing, перегрузкой MES и медленной работой операторского dashboard.

Работа разбита на пять связанных архитектурных задач.

## Логика проекта

```text
Сначала:
измерить и сделать систему наблюдаемой

Затем:
обеспечить delivery guarantees

После:
вынести тяжёлый pricing из synchronous path

Параллельно:
ускорить read-path операторов

Далее:
масштабировать и повышать HA
```

Главный принцип проектной работы — **эволюционное улучшение существующей архитектуры вместо полного rewrite**. Каждая инициатива должна давать измеримый бизнес-эффект и не увеличивать риск потери заказов.
